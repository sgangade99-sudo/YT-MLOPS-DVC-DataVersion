step wise instruction of DVC

step 1 : create a git repo and colne it in local.
step 2 : Create mycode.py and code to it. (it will save a csv file to a new "data" folder)
step 3 : Do a git add-commit-push before initialing DVC.
(pip install dvc)
step 4 : Now we do dvc init (created .dvcignore, .dvc)
step 5 : now do "mkdir S3" (creates a new S3 directory)
step 6 : now we do "dvc remote add -d myremote S3"
step 7 : Next "dvc add data/"
         Now it will ask to do : ("git rm -r --cached 'data'" and "git commit -m 'stop tracking data'")
         Because initially we were tracking data/ folder from git so now we remove it for dvc to handle
step 8 : Again we do "dvc add data/" (creates data.dvc) then "git add .gitignore data.dvc"
